# Roadmap (after v1.0.0)

Possible future work, **not included in 1.0.0**:

- Balance review of part mass, cost, technology placement and time to deploy.
- Broader KSP compatibility testing, Kerbalism integration, and mod-interaction checks.
- Additional texture/visual variants and localization.
- Regression tests for save/load, detached docking ports and special-case action groups.

Please use GitHub Issues to report regressions, especially physics contacts during deployment.

## Future storage pods

- Add two-chamber pods with independent liquid storage in each chamber.
- Add hard-sided pods for raw materials, including Ore.
